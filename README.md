# 🏠 Real Estate Price Prediction System

##  Overview
This project focuses on predicting real estate prices using machine learning techniques. The main goal was to compare multiple regression models and identify the best-performing one for accurate predictions.

---

##  What I Did
- Cleaned and prepared the dataset
- Implemented 13 different regression algorithms
- Compared model performance using evaluation metrics
- Selected the best model based on results
- Saved the model using pickle
- Built a Flask web application for predictions

---

##  Models Used
- Linear Regression
- Ridge, Lasso, ElasticNet
- Polynomial Regression (with Pipeline)
- Random Forest
- XGBoost
- LightGBM
- Support Vector Machine (SVM)
- Neural Network (MLP)
- KNN
- SGD, Huber

---

##  Evaluation Metrics
- Mean Absolute Error (MAE)
- Mean Squared Error (MSE)
- R² Score

---

## Tech Stack
- Python
- Pandas, NumPy
- Scikit-learn
- XGBoost, LightGBM
- Flask
